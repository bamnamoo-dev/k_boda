# PrismView

윈도우 10/11 전용의 빠르고 가벼운 고성능 이미지 뷰어입니다.  
"꿀뷰"처럼 열자마자 사진이 뜨고, 키보드만으로 빠르게 넘겨볼 수 있습니다.

---

## 주요 기능

1. **초고속 이미지 표시**:
   - Rust 디코딩 오버헤드 없이 WebView2(Edge 엔진)의 하드웨어 가속으로 이미지를 즉시 표시합니다.
   - 지원 포맷: JPG, JPEG, PNG, GIF, WebP, AVIF, BMP, SVG.
   - 앞뒤 2장 메모리 프리로드(decode)로 딜레이 없는 넘김.
2. **자연스러운 줌 & 패닝**:
   - 마우스 커서 위치 중심 부드러운 줌 (마우스 휠, Ctrl+휠 핀치 줌).
   - 화면 밖 이탈 방지 마우스 드래그 패닝.
   - 100% 실제 크기(1:1 픽셀 매핑, 윈도우 배율 150% 완벽 대응) ↔ 화면 맞춤 더블클릭 토글.
3. **폴더 탐색 & 자연 정렬**:
   - 윈도우 탐색기와 동일한 자연 정렬(1, 2, 10 순서) 지원.
   - 설정에 따라 이름순, 수정 날짜순, 파일 크기순(오름차순/내림차순) 정렬 지원.
   - 마지막 장 도달 시 다음 폴더로 자동 연속 이동 옵션.
4. **가상 스크롤 필름스트립 & 스마트 캐시**:
   - 화면에 보이는 썸네일만 렌더링하는 가상 스크롤 (`T`).
   - `%LOCALAPPDATA%\PrismView\thumbnails`에 썸네일 캐시를 저장하며 500MB 초과 시 오래된 파일 자동 청소.
5. **상세 정보 및 AI 프롬프트 분석**:
   - EXIF 메타데이터(카메라, 렌즈, 촬영일시, 조리개, 셔터, ISO, 초점거리) 표시 (`I`).
   - Stable Diffusion/Midjourney 등 PNG 파일 내 AI 생성 프롬프트 자동 감지 및 원클릭 복사.
   - 파일이 선택된 상태로 윈도우 파일 탐색기 열기 연동.
6. **회전, 무손실 사본 저장 & 휴지통 삭제**:
   - 시계 방향(`R`), 반시계 방향(`Shift+R`) 즉시 회전.
   - 회전 상태를 원본 손상 없이 `파일명_rotated.확장자` 사본으로 저장 (`Ctrl+S`).
   - `Delete` 또는 `Shift+Delete` 시 확인 창을 거쳐 윈도우 휴지통으로 안전하게 이동.
7. **클립보드 연동**:
   - `Ctrl+C`: 현재 회전 각도가 반영된 이미지를 클립보드에 복사(카카오톡, 포토샵 등에 바로 붙여넣기).
   - `Ctrl+Shift+C`: 파일 전체 경로 복사.
8. **ZIP / CBZ 만화책 아카이브 지원**:
   - 전체 압축 해제 없이 필요한 페이지만 온디맨드로 즉시 파싱.
   - 한글 파일명이 깨지지 않도록 CP949(EUC-KR) 인코딩 자동 보정.
9. **양면 보기 & 배경색 전환**:
   - 두 장 나란히 표시 (`D`), 좌→우 및 일본 만화식 우→좌 읽기 방향 전환.
   - 검정 → 짙은 회색 → 체크무늬(투명 PNG 확인용) 배경 순환 (`B`).
10. **윈도우 파일 연결 & 단일 인스턴스**:
    - 이미지 파일 더블클릭 및 "연결 프로그램"에서 PrismView 연결 지원.
    - 이미 실행 중일 때 다른 파일을 열면 새 창 대신 기존 창에 포커스하며 바로 열림.
    - 창 위치, 크기, 최대화 상태 자동 기억 및 복원.
    - 환경 설정 (`Ctrl+,`) 및 단축키 안내 (`H`, `F1`).

## Windows SmartScreen 경고 안내 ("Windows의 PC 보호")

PrismView를 처음 설치하거나 실행할 때 아래와 같은 파란색 화면이 나타날 수 있습니다:

> **Windows의 PC 보호**  
> Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

### 경고가 뜨는 이유
- PrismView는 개인 개발자용 오픈소스 무료 소프트웨어입니다.
- 연간 수십만~수백만 원의 비용이 드는 기업용 상용 코드 서명 인증서(EV Code Signing)를 사용하지 않으므로, 윈도우 운영체제가 앱의 신뢰도를 처음 확인할 때 띄우는 정상적인 보안 안내입니다.
- 바이러스나 악성코드가 아니며 모든 소스코드는 투명하게 공개되어 있습니다.

### 실행 방법
1. 팝업 창 본문의 **[추가 정보]** 파란색 링크를 클릭합니다.
2. 우측 하단에 새롭게 나타나는 **[실행]** 버튼을 클릭합니다.
3. 이후에는 경고 없이 바로 실행됩니다.

## 단축키 표

### 탐색
| 단축키 | 동작 |
| :--- | :--- |
| `→`, `PageDown`, `Space`, 마우스 5번 버튼 | 다음 이미지로 이동 |
| `←`, `PageUp`, `Backspace`, 마우스 4번 버튼 | 이전 이미지로 이동 |
| `Home` / `End` | 첫 번째 / 마지막 이미지로 이동 |

### 화면 및 배율
| 단축키 | 동작 |
| :--- | :--- |
| 마우스 휠, `Ctrl` + 휠 | 커서 위치 중심 확대 / 축소 |
| `+` / `-` | 화면 중심 확대 / 축소 |
| `0` / `1` | 화면에 맞춤 / 100% 실제 크기 (1:1 픽셀) |
| 마우스 더블클릭 | 화면 맞춤 ↔ 100% 토글 |
| 마우스 좌클릭 드래그 | 확대 상태에서 화면 이동 (패닝) |
| `F`, `Enter`, `F11` / `Escape` | 전체화면 전환 / 해제 |

### 보기 모드 & 조작
| 단축키 | 동작 |
| :--- | :--- |
| `R` / `Shift` + `R` | 시계 방향 90° / 반시계 방향 90° 화면 회전 |
| `Ctrl` + `S` | 회전 상태 사본으로 저장 (`_rotated`) |
| `D` | 양면 보기 토글 (좌→우 / 우→좌 만화) |
| `B` | 배경색 순환 (검정 → 짙은 회색 → 체크무늬) |

### 파일 & 부가 기능
| 단축키 | 동작 |
| :--- | :--- |
| `Ctrl` + `O` | 파일 열기 대화상자 |
| `Ctrl` + `C` | 현재 이미지를 클립보드에 복사 |
| `Ctrl` + `Shift` + `C` | 현재 파일 전체 경로를 클립보드에 복사 |
| `Delete`, `Shift` + `Delete` | 휴지통으로 파일 이동 (안전 삭제 확인창) |
| `T` | 하단 필름스트립(썸네일 목록) 토글 |
| `I` | 우측 이미지 정보 / EXIF / AI 프롬프트 패널 토글 |
| `Ctrl` + `,` | 환경 설정 (다크/라이트 테마, 정렬, 폴더 연속 넘김) |
| `H`, `F1` | 전체 단축키 도움말 모달 |

## 개발 및 빌드 방법

### 요구 사항
- Windows 10/11 (64비트)
- Node.js (v18 이상 권장)
- Rust 툴체인 (`x86_64-pc-windows-msvc`)
- WebView2 런타임 (Windows 10/11 기본 내장)

### 개발 서버 실행
```powershell
npm install
npm run tauri dev
```

### NSIS 설치 파일 빌드
```powershell
npm run tauri build
```
빌드가 완료되면 `src-tauri/target/release/bundle/nsis/` 디렉터리에 설치 파일(`.exe`)이 생성됩니다.
