# PrismView (v1.0.0)

윈도우 10/11 전용의 빠르고 가벼운 초경량 이미지 뷰어입니다.  
"꿀뷰"처럼 열자마자 사진이 뜨고, 키보드만으로 시원시원하게 넘겨볼 수 있습니다.

---

## 🔒 개인정보 보호 안내 ("사진은 PC 밖으로 전송되지 않습니다")

> **PrismView는 100% 완전 오프라인으로 작동합니다.**  
> - 공무원증/증명사진 얼굴 인식(MediaPipe BlazeFace), 사진 회전/자르기/보정, 모자이크/흐림, 일괄 변환, CAD 도면 열람 등 모든 처리가 사용자 PC 내부 로컬에서만 수행됩니다.  
> - 외부 인터넷(클라우드)으로의 사진 전송이나 원격 서버 통신 요청(0건)은 일절 발생하지 않으므로, 개인 사진이나 공무원증 서류 사진, 기업 도면도 안심하고 열람·편집하실 수 있습니다.

## 1. 다운로드 및 설치 방법

### [설치 프로그램 (`PrismView_1.0.0_x64-setup.exe`)]
1. 배포된 `PrismView_1.0.0_x64-setup.exe` 파일을 실행합니다.
   * 관리자 권한 요청 창 없이 현재 사용자 폴더(`%LOCALAPPDATA%\Programs\PrismView`)에 안전하게 설치됩니다.
2. 설치 중 바탕화면 바로가기 생성을 선택하실 수 있습니다.
3. 주요 이미지 포맷(JPG, PNG, GIF, WebP, AVIF, BMP, SVG, TIFF, HEIC, ZIP, CBZ)이 PrismView와 자동 연결됩니다.
   * *참고: CAD 사용자의 기존 환경 보호를 위해 `.dwg`, `.dxf`는 설치 시 자동 연결되지 않으며, 설정에서 원하실 때만 켜실 수 있습니다.*

### [Windows SmartScreen 경고 대처법 ("Windows의 PC 보호")]
설치 파일이나 실행 파일을 처음 열 때 아래와 같은 파란색 화면이 나타날 수 있습니다:
> **Windows의 PC 보호**  
> Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

- **원인:** 무료 오픈소스 소프트웨어로, 연간 수백만 원에 달하는 기업용 EV 코드 서명 인증서를 구입하지 않아 발생하는 윈도우 OS의 초기 평판 안내입니다.
- **해결 방법:**  
  1) 화면의 **[추가 정보]** 파란색 글씨를 클릭합니다.  
  2) 우측 하단에 나타나는 **[실행]** 버튼을 클릭하면 즉시 정상 설치 및 실행됩니다.

### [프로그램 제거 방법]
- Windows "설정" → "앱" → "설치된 앱 (앱 및 기능)"에서 **PrismView**를 찾아 [제거]를 클릭합니다.
- 제거 마법사가 실행되면서 **"설정 및 썸네일·도면 캐시를 함께 삭제하시겠습니까?"**를 묻습니다.
  - **아니요(기본 권장):** 다음 재설치나 업데이트 시 즐겨찾기/설정을 유지하기 위해 보존합니다.
  - **예:** 모든 개인 설정과 캐시를 깨끗하게 영구 삭제합니다.

## 2. 무설치 포터블 버전 (`PrismView_1.0.0_portable.zip`)

설치 과정 없이 USB나 외장 드라이브에 넣고 다니며 어디서나 즉시 사용할 수 있습니다.

- 압축을 풀고 폴더 내 `PrismView.exe`를 실행하시면 바로 동작합니다.
- 윈도우 레지스트리를 건드리지 않으며, 시스템 파일 연결을 강제하지 않습니다.
- **데이터 격리:** 모든 설정 파일과 캐시는 실행 파일 옆의 `data` 폴더 안에만 저장되어 설치 버전과 섞이지 않습니다.
- **쓰기 제한 환경 대응:** 읽기 전용 USB나 쓰기 권한이 없는 폴더에서 실행하더라도 앱이 오류로 멈추지 않고 시스템 임시 폴더(Temp)로 캐시를 안전하게 우회 처리합니다.

## 3. 공무원증 사진 만드는 법 (3줄 요약)

1. 사진을 열고 단축키 **`Shift + P`**를 누르면 인공지능(AI)이 얼굴을 찾아 3:4 공무원증 규격 틀에 자동 맞춤합니다.
2. 마우스 드래그로 위치와 턱선/정수리를 정밀 조정한 뒤 **`Enter`**를 누릅니다.
3. 자동으로 **354×472 px, 소문자 .jpg, 150KB 미만, 메타데이터 제거**된 공무원증 표준 규격으로 저장되며 초록색 **"규격 통과"** 배지가 표시됩니다.

## 4. 단축키 요약

### 탐색 및 기본 조작
| 단축키 | 동작 |
| :--- | :--- |
| `Tab` | 뷰어 모드 ↔ 탐색기(그리드 목록) 모드 전환 |
| `→` / `←`, 마우스 휠 | 다음 / 이전 이미지로 넘기기 |
| `Space` | 슬라이드쇼 재생 / 일시정지 (탐색기에서는 사진 열기) |
| `Backspace` | 상위 폴더로 이동 (탐색기) |
| `Home` / `End` | 폴더의 첫 번째 / 마지막 이미지로 이동 |
| `F` | 창 크기에 맞춤 (원본이 창보다 클 때만 축소) |
| `1` | 100% 원본 픽셀 크기로 보기 (1:1 매핑) |
| `+` / `-` | 화면 확대 / 축소 (마우스 커서 중심 줌) |
| `F11` | 전체 화면 토글 |
| `I` | 사진 상세 정보 (EXIF, 촬영 일시, AI 프롬프트) 패널 토글 |
| `H` 또는 `F1` | 단축키 안내 및 PrismView 정보 창 열기 |

## 5. 원본 PNG로 앱 아이콘(.ico) 생성하는 방법

고해상도 원본 PNG 이미지(`app-icon.png`, 1024×1024 권장) 하나만 있으면 아래 명령어로 윈도우에 필요한 모든 크기의 `.ico` 및 다중 해상도 PNG를 한 번에 생성할 수 있습니다:

```powershell
# Tauri 내장 아이콘 생성 CLI 도구 실행
npx @tauri-apps/cli icon app-icon.png
```
실행하면 `src-tauri/icons/` 폴더에 32x32, 128x128, Square 시리즈 및 `icon.ico`가 자동으로 빌드되어 즉시 설치 프로그램과 앱에 적용됩니다.

PrismView는 다음 오픈소스 소프트웨어들의 기여로 만들어졌습니다:

| 구성 요소 | 버전 | 라이선스 | 용도 및 격리 구조 |
| :--- | :--- | :--- | :--- |
| **GNU LibreDWG** | 0.14 | GPLv3+ | DWG→DXF 도면 변환 독립 실행기 (`dwg2dxf.exe`, sidecar 프로세스 격리 호출) |
| **MediaPipe Tasks Vision** | 1.1.x | Apache 2.0 | 로컬 딥러닝 BlazeFace 얼굴 검출 모델 (100% 오프라인 구동) |
| **React / ReactDOM** | 19.x | MIT | 프론트엔드 UI 프레임워크 |
| **Tauri Framework** | 2.x | MIT / Apache 2.0 | 데스크톱 앱 런타임 및 WebView2 바인딩 |
| **dxf-parser** | 1.1.2 | MIT | DXF 도면 파서 |
| **Lucide Icons** | 1.60.x | ISC | UI 아이콘 |
| **image, tiff, zip, trash, pdf-writer** | 최신 | MIT / Apache 2.0 / BSD | 이미지 처리, PDF 묶기, 압축 해제, 휴지통 삭제 연동 |

*라이선스 전문은 앱 내 도움말(H)의 [오픈소스 라이선스] 탭 및 설치 폴더의 `LICENSES.txt`, `GPLv3.txt`에서 확인하실 수 있습니다.*
